# See Now

Let the model watch your screen (or camera / video file) live. Only frames whose picture changed enough are kept, packed into one image.

- `see_now({ action: "watch" })`: block for one current sheet
- `status` / `window` / `region`: inspect, control the floating window, pick a region
- Settings: pacing, tiers, window style, transcription service

See the repository README for full usage and platform requirements.
